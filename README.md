# Sound Record

Приложение в трее для записи и расшифровки звонков (Windows, .NET 10, WinForms + NAudio, Whisper.net, sherpa-onnx).

## Запись

- Пишет одновременно **выход** (WASAPI loopback устройства воспроизведения по умолчанию — голоса собеседников) и **микрофон** по умолчанию, сводит их в один файл.
- Формат: MP3 96 kbps стерео (LAME сам выбирает 32 кГц) — около 43 МБ в час.
- Файлы: `yyyy-MM-dd_HH-mm-ss.mp3`, расшифровка рядом с тем же именем `.txt`. Папка по умолчанию `Документы\Sound Records`, меняется пунктом «Папка для записей…» (текущая видна в подсказке пункта; новая папка действует со следующей записи).
- Меню в трее: начать / пауза / стоп, режим распознавания, «Распознать файл…», открыть папку, папка для записей, выход. Двойной клик по иконке открывает папку.

## Индикация

- Цвет иконки: серая — ожидание, красная — запись, жёлтая — пауза.
- Идёт обработка (скачивание моделей, загрузка модели, расшифровка) — вокруг иконки синее кольцо прогресса; пока процент неизвестен, кольцо крутится. Этап и процент видны первой строкой меню и в подсказке иконки.
- Ошибка — уведомление Windows, красный значок «!» на иконке и пункт с текстом ошибки в начале меню. Клик по нему (или по уведомлению) открывает `SoundRecord.log` и снимает значок. Ловятся: недоступное устройство при старте, отключение устройства во время записи, сбой записи на диск (запись останавливается и сохраняется), ошибки скачивания моделей и распознавания, любые необработанные исключения.

## Распознавание речи

Полностью локальное, русский и английский (язык определяется для каждой фразы отдельно).

Во время записи, если распознавание включено, микрофон и звук из динамиков дополнительно пишутся в две временные дорожки (16 кГц WAV, `%TEMP%\SoundRecord`, ~115 МБ в час каждая). После «Стоп» по ним делается точная расшифровка: речь с микрофона — «Я», звук из динамиков делится по голосам (pyannote) на «Спикер 1», «Спикер 2», … Затем дорожки удаляются.

| Режим | Как работает |
|---|---|
| Онлайн | Во время записи в `.txt` дописывается черновик — каждая фраза через пару секунд после того, как прозвучала; голоса из динамиков различаются по отпечатку голоса на лету (грубее). После «Стоп» черновик заменяется точной расшифровкой. |
| После записи | Только точная расшифровка после «Стоп». |
| Отключено | Только запись. |

«Распознать файл…» обрабатывает любой аудиофайл; отдельных дорожек у него нет, поэтому голоса делятся по всему файлу и «Я» не выделяется. Расшифровки выполняются по очереди. Файл расшифровки пишется во временный `.txt.tmp` и заменяет `.txt` только целиком.

Выбранный режим хранится в `settings.json` рядом с exe, ошибки пишутся в `SoundRecord.log` там же.

### Модели

Скачиваются автоматически в папку `models` рядом с exe (в git не попадают), как только выбран режим распознавания:

| Файл | Размер | Назначение |
|---|---|---|
| `ggml-large-v3-turbo-q8_0.bin` | 834 МБ | Whisper — речь в текст |
| `wespeaker_en_voxceleb_resnet34_LM.onnx` | 25 МБ | голосовой отпечаток спикера |
| `pyannote-segmentation-3-0.onnx` | 6 МБ | разметка «кто когда говорит» |
| `silero_vad.onnx` | 0.6 МБ | поиск фраз |

Whisper загружается в видеопамять (~850 МБ) только на время распознавания — при старте онлайн-записи или расшифровки — и выгружается через минуту простоя. Загрузка занимает 2–4 секунды; в онлайн-режиме звук за это время копится и обрабатывается следом. Остальные модели маленькие и создаются на время каждой операции.

Whisper работает на дискретной видеокарте через Vulkan (нужен только обычный драйвер). Встроенная видеокарта не используется: на ноутбуке с Radeon 890M + RTX 4070 whisper.cpp по умолчанию брал встроенную и падал при загрузке модели. Без дискретной видеокарты распознавание идёт на процессоре, заметно медленнее.

Скорость на RTX 4070 Laptop: звонок 3.5 минуты расшифровывается примерно за 1–1.5 минуты (разделение голосов на процессоре ~20 с, Whisper ~1 с на реплику).

## Сборка и запуск

```
dotnet build -c Release
bin\Release\net10.0-windows\SoundRecord.exe
```

Нативные библиотеки (`libmp3lame.*.dll`, `runtimes\...`) должны лежать рядом с exe, поэтому single-file publish не подходит.

## Ограничения

- Устройства берутся те, что выбраны в Windows по умолчанию на момент старта записи. Если приложение для звонков выводит звук на другое устройство (например, на гарнитуру, назначенную «устройством связи»), собеседников не будет слышно в записи.
- Отключённое во время записи устройство дальше пишется тишиной (об этом приходит уведомление); переключения на новое устройство нет.
- Без наушников микрофон слышит динамики, и речь собеседников может попасть в расшифровку ещё раз с подписью «Я».
- Черновик онлайн-режима может разбить одного человека на двух спикеров или склеить похожие голоса — точная расшифровка после «Стоп» это исправляет.
