# Sound Record

Приложение в трее для записи звонков (Windows, .NET 10, WinForms + NAudio).

- Пишет одновременно **выход** (WASAPI loopback устройства воспроизведения по умолчанию — голос собеседника) и **микрофон** по умолчанию, сводит их в один файл.
- Формат: MP3 96 kbps стерео (LAME сам выбирает 32 кГц) — около 43 МБ в час.
- Файлы: `Документы\Sound Records\yyyy-MM-dd_HH-mm-ss.mp3`.
- Меню в трее: начать / пауза / стоп / открыть папку / выход. Двойной клик по иконке открывает папку.
- Цвет иконки: серая — ожидание, красная — запись, жёлтая — пауза.

## Сборка и запуск

```
dotnet build -c Release
bin\Release\net10.0-windows\SoundRecord.exe
```

Рядом с exe должны лежать `libmp3lame.64.dll` / `libmp3lame.32.dll` (их копирует пакет NAudio.Lame), поэтому single-file publish не подходит.

## Ограничения

- Устройства берутся те, что выбраны в Windows по умолчанию на момент старта записи. Если приложение для звонков выводит звук на другое устройство (например, на гарнитуру, назначенную «устройством связи»), собеседника не будет слышно в записи.
- Смена или отключение устройства во время записи не отслеживается: с этого момента отключённый источник пишется тишиной.
