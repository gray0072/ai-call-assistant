# Sound Record

Приложение в трее для записи и расшифровки звонков (Windows, .NET 10, WinForms + NAudio, Whisper.net, sherpa-onnx).

## Запись

- Пишет одновременно **выход** (WASAPI loopback устройства воспроизведения по умолчанию — голоса собеседников) и **микрофон** по умолчанию, сводит их в один файл.
- Формат: MP3 96 kbps стерео (LAME сам выбирает 32 кГц) — около 43 МБ в час.
- Файлы: `Документы\Sound Records\yyyy-MM-dd_HH-mm-ss.mp3`, расшифровка рядом с тем же именем `.txt`.
- Меню в трее: начать / пауза / стоп, режим распознавания, «Распознать файл…», открыть папку, выход. Двойной клик по иконке открывает папку.
- Цвет иконки: серая — ожидание, красная — запись, жёлтая — пауза. Ход распознавания виден первой строкой меню и в подсказке иконки.

## Распознавание речи

Полностью локальное, русский и английский (язык определяется для каждой фразы отдельно).

| Режим | Как работает |
|---|---|
| Онлайн | Микрофон и звук из динамиков разбираются отдельно. Фразы с микрофона подписываются «Я», голоса из динамиков различаются по голосовому отпечатку («Спикер 1», «Спикер 2», …). Каждая фраза дописывается в `.txt` через несколько секунд после того, как прозвучала. |
| После записи | После «Стоп» весь файл размечается по голосам (pyannote), затем каждая реплика распознаётся. Голоса различаются точнее, чем онлайн, но «Я» не выделяется — все участники, включая вас, это «Спикер N». |
| Отключено | Только запись. |

«Распознать файл…» обрабатывает любой аудиофайл так же, как режим «После записи». Расшифровки выполняются по очереди.

Выбранный режим хранится в `settings.json` рядом с exe, ошибки пишутся в `SoundRecord.log` там же.

### Модели

Скачиваются автоматически при первом использовании в папку `models` рядом с exe (в git не попадают):

| Файл | Размер | Назначение |
|---|---|---|
| `ggml-large-v3-turbo-q8_0.bin` | 834 МБ | Whisper — речь в текст |
| `wespeaker_en_voxceleb_resnet34_LM.onnx` | 25 МБ | голосовой отпечаток спикера |
| `pyannote-segmentation-3-0.onnx` | 6 МБ | разметка «кто когда говорит» |
| `silero_vad.onnx` | 0.6 МБ | поиск фраз в потоке (онлайн) |

Whisper работает на дискретной видеокарте через Vulkan (нужен только обычный драйвер). Встроенная видеокарта не используется: на ноутбуке с Radeon 890M + RTX 4070 whisper.cpp по умолчанию брал встроенную и падал при загрузке модели. Без дискретной видеокарты распознавание идёт на процессоре, заметно медленнее. Модель остаётся в видеопамяти (~1 ГБ) до выхода из приложения.

Скорость на RTX 4070 Laptop: звонок 3.5 минуты расшифровывается «после записи» примерно за минуту (разделение голосов на процессоре ~15 с, Whisper ~1 с на реплику).

## Сборка и запуск

```
dotnet build -c Release
bin\Release\net10.0-windows\SoundRecord.exe
```

Нативные библиотеки (`libmp3lame.*.dll`, `runtimes\...`) должны лежать рядом с exe, поэтому single-file publish не подходит.

## Ограничения

- Устройства берутся те, что выбраны в Windows по умолчанию на момент старта записи. Если приложение для звонков выводит звук на другое устройство (например, на гарнитуру, назначенную «устройством связи»), собеседников не будет слышно в записи.
- Смена или отключение устройства во время записи не отслеживается: с этого момента отключённый источник пишется тишиной.
- Онлайн-режим без наушников: микрофон слышит динамики, и речь собеседников может попасть в расшифровку ещё раз с подписью «Я».
- Онлайн-режим может разбить одного человека на двух спикеров или склеить похожие голоса — режим «После записи» в этом точнее.
